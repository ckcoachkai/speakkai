# Garden winner dance studio

The Plants vs. Zombies name picker's winner reveal now lazy-loads the selected animal as a real Blender-authored skinned 3D character. All ten existing animal choices are retained. Each has a 64-bone skeleton, individually jointed fingers, spine/neck/head, jaw, eye/brow parts, ears, feet/toes and a five-part tail rig. Some species have no visible tail. The style is a textured animal mascot with human dance anatomy, not a photoreal animal scan.

Four original eight-second routines are baked at 30 fps and 120 BPM: square dance, shuffle, hip-hop and disco. Hands and feet use authoring IK; the runtime interpolates baked skeletal clips and crossfades styles. These are original procedural choreography, not motion capture or reproductions of a particular performer. Clothing uses continuous weighted surfaces around elbows, knees and the torso. The runtime adds physically lit materials, directional shadows and a stage plinth.

`public/games/games/winner-dance-3d.js` owns the renderer, loading, clip selection and disposal. The app preserves its 2D fallback while 3D loads, on asset errors, when WebGL is unavailable, and after context loss. Generation guards prevent an old download from attaching to a new result. Motion pauses when the document is hidden; reduced-motion users see a static pose. Music remains opt-in. Continue cancels animations, audio and pending loads and disposes GPU resources. No combat, roster, fairness, winner-selection or other game logic changes.

## Rebuild

Run Blender 5.2 or later in background mode, passing the repository and an output directory:

```
blender --background --python tools/garden-dance/build_dancers.py -- REPOSITORY OUTPUT_DIRECTORY
```

The script writes ten GLBs and a manifest to `public/games/assets/dancers`, plus a packed editable `Garden-Dancer.blend` and an FBX with all four routines to the output directory. Optional species arguments after the output directory build a subset. All geometry, rigging and animation are generated by the checked-in script.

Pack the generated GLBs for browser delivery (requires Node and sharp):

```
node tools/garden-dance/optimize_glb.cjs public/games/assets/dancers
node scripts/check-garden-dance.mjs
```

For the browser lifecycle checks, serve the site at port 4179 (for example `npm run dev -- --port 4179`), then run `node scripts/check-garden-dance-browser.cjs`. Set `DANCE_BASE_URL` for a different URL, `BROWSER_CHANNEL=msedge` to use an installed Edge in headless mode, and `DANCE_EVIDENCE_DIR` for screenshots. The checks cover a real accelerated garden result, all four styles, pixel-stable pause/reduced-motion states, portrait/landscape layout, Continue cleanup, asset failure, context loss and cancellation during loading.

The original ChatGPT-generated material atlas is retained as `material-atlas.png`. Browser GLBs embed a resized JPEG atlas plus a proper fur normal map derived from the generated height detail. The packer calculates explicit surface tangents and removes unused constant animation channels. They need no remote asset host or compression decoder. Local Three.js and its GLTFLoader already exist in this game's vendor directory.

## Unreal authoring

The supplied Unreal 5.8 project enables Python and editor scripting. With the FBX one directory above the project, run:

```
UnrealEditor-Cmd GardenDance.uproject -run=pythonscript -script=REPOSITORY/tools/garden-dance/import_unreal.py -unattended -nullrhi -nosplash
```

The script imports the skeletal mesh, materials, skeleton and four animation sequences, then saves `/Game/GardenDance/DanceStudio`, with a dancer, plinth, lighting and camera. `unreal-validation.json` records the imported assets and engine version. This is an editable Unreal authoring project; the website uses the portable GLBs in WebGL. Unreal's commandlet import validates assets without opening the host editor. It does not validate an Unreal-rendered cinematic.

## Generated material provenance

Created with the built-in ChatGPT image generator on 2026-11-10, then embedded on the original 3D models. No third-party model or dance animation was downloaded. Prompt:

> Use case: stylized-concept. Asset type: production albedo texture atlas for a realistic friendly 3D animal mascot wearing street dance clothing. Create a square image with EXACTLY four equal square quadrants, seamlessly textured materials, no scene, no objects, no lettering, no borders, no shadows or directional lighting. Top left quadrant: fine warm grey beige mammal fur, densely detailed short soft hairs, uniform natural coloration. Top right quadrant: premium deep charcoal indigo woven sweatshirt knit cotton fabric, subtle fine fibers. Bottom left quadrant: off-white pebbled sneaker leather, soft small pores. Bottom right quadrant: muted teal technical fabric micro weave. Orthographic flat evenly lit texture material scan. Texture detail should be realistic and tasteful, not illustrative. Each quadrant must be filled edge to edge with its material. This will wrap a fully rigged 3D dancing animal character in a classroom browser game.
