# Published Death Room

Source is retained in this directory; runtime assets are in ../../public/games/death-room/assets.
To rebuild, run npm ci, copy the runtime asset directories to public/assets locally, then npm run build -- --base=/games/death-room/. Copy generated files to ../../public/games/death-room without source .blend files. Preserve third-party notices.

Performance release: DPR capped at 1.5, 2048 shadow maps, 30 Hz shadow/HUD updates, anisotropy 8, hidden-tab suspension. Controlled headless Edge preview at 1280x720 DPR2 with nine actors measured 27.3 FPS before and 52.5 FPS after (six seconds each); this is not an all-device guarantee. Subpath smoke covers all ten previews and one start/reveal/reset cycle, with zero browser errors or asset failures.

Loading release: nine character GLBs now reference content-hashed shared texture files. Character transfer is 50,676,819 bytes instead of 124,161,896 bytes (59.2% less). All 86 image references and 5,431 geometry/animation buffer views were verified byte-identical; no texture resizing or lossy compression. Player456 starts loading concurrently with the main cast, and THREE image caching deduplicates concurrent shared texture requests. Original authoring GLBs remain untouched. Recreate web assets from originals using scripts/share-cast-textures.mjs before building. All ten Start/Pause/Resume/Reveal/Reset cycles and fullscreen pass with nine real rigs, no browser errors or failed assets.
Controlled cold-start headless Edge test with 10 Mbps / 40 ms network simulation: ready in 102.7 s before versus 47.6 s after (53.6% faster). Nine actors in both; zero page errors. This is a controlled comparison, not a guarantee for live networks or devices.

Fluid movement release: frame-rate-independent crossfades preserve outgoing crouch/swim/celebration poses and eased turn acceleration reduces snapping. Six non-graphic contact cues use one instanced draw call, at most 96 flecks and per-actor/category throttles. Reduced-motion preference, effects toggle, reset, frozen poses and VIP immunity verified. All ten room cycles/fullscreen passed with no errors or missing assets. Eight-second preview sample: 84.5 FPS before and 96.9 after on this machine; evidence of no observed regression, not a guaranteed FPS increase. No new media downloads.
