# 30× QA Review

Run for every new test.

1. Does the route resolve?
2. Does the production build succeed?
3. Are there console errors?
4. Are all required assets present?
5. Does the Test 1–50 navigator work?
6. Is the active test clearly identified?
7. Does the primary CTA work?
8. Does 1920×1080 fit?
9. Does 1600×900 fit?
10. Does 1440×900 fit?
11. Does 1366×768 fit?
12. Is horizontal overflow absent?
13. Is SpeakKai identifiable in five seconds?
14. Is Coach Kai identifiable in five seconds?
15. Is the offering understandable?
16. Is the primary stakeholder clear?
17. Is a trust cue visible or one interaction away?
18. Are programs/services discoverable?
19. Is the method/process discoverable?
20. Is contact/booking discoverable?
21. Is text readable?
22. Is contrast adequate?
23. Is keyboard use complete?
24. Do hover interactions have click/touch/focus equivalents?
25. Does reduced motion preserve the experience?
26. Is motion purposeful and smooth?
27. Are heavy media and animation isolated to the active route?
28. Are all claims factual and privacy-safe?
29. Is the design clearly different from adjacent tests?
30. Would a professional design review keep this concept?

For each failure record:

- severity
- screenshot
- cause
- fix
- re-test result
