The prompt requested twelve separate transparent detailed anime mecha armor components: chest, helmet, shoulder, upper arm, forearm, thigh, shin, foot, wing pack, rifle, glove, waist. White pearl titanium, blue accents, gold details, panel lines and metallic shading, all facing three-quarter right. This is newly generated kit-inspired artwork, not official model-kit photography or ripped game art.

The source pixels were preserved. JSON rectangles select each isolated component (the generated spacing was not an exact grid). Ten configurations use wing pack count, armor proportions, gun barrels, trim palette and independent motion phase; they are not exact recreations of ten Bandai model kits.
