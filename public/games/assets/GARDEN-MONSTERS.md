# Sourced garden creature animation

Downloaded character pixels are rendered by games/garden-monsters.js. Source URLs, original timelines, interpolation, rectangles, hashes and rights are in garden-sourced/manifest.json. No replacement character is hand-drawn or AI-generated.

Every active picker lane independently permits giant spawns after the first wave, with one living giant per lane. Regular zombie stats never scale with time; queued zombies create difficulty. Giant height is224logical pixels versus112for normal bodies (2times), with ordinary zombie size unchanged. Giant clips span the shared lawn behind readable players/plants; a ground marker identifies their target lane.

Dog Man, Hello Kitty, Pikachu and Niu Lai face the player column on the left. Dog Man is no longer mirrored away. Kitty uses a genuine profile/three-quarter pose, retaining its original magnifying glass; detached question marks were removed. Pikachu's detailed native407×339 movie artwork replaces the old60pxsprite, with smooth image scaling. Niu Lai uses actual opening-movie up-left profile frames.

Combat stays at fixed40ms steps while painted positions and clocks interpolate at display refresh. Eight source cycles have baked optical-flow frames targeting60fps; the duck retains150authored frames at30fps. Separate instance playheads and100ms transitions preserve feet and timing without consuming combat RNG.
