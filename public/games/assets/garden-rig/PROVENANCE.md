# Garden character rigs

This directory contains 189 original transparent PNG body parts (525,367 bytes) sourced from [FregD156/PvZ_Assets](https://github.com/FregD156/PvZ_Assets/tree/8ba94e95cfe7d0de5682f8258d3b932dbdac885c/reanim), pinned to commit `8ba94e95cfe7d0de5682f8258d3b932dbdac885c`. Each PNG is preserved byte for byte; `manifest.json` records the source path, Git blob SHA, dimensions and alpha bounds for every image. The downloads were checked against their Git blob hashes before inclusion.

The manifest embeds the unchanged PNG bytes as data URLs, reducing production startup to one manifest request. The saved source PNGs and the decoded data URLs were both verified against their original Git blob SHAs. Standalone play can use the manifest object directly without any external image requests.

The manifest also contains selected original animation tracks from PeaShooterSingle, PeaShooter, SnowPea, ThreePeater, GatlingPea, Melonpult, Cornpult, Cactus, Wallnut, Tallnut, SunFlower, Zombie, Zombie_football, Zombie_paper and Zombie_polevaulter. Missing keyframe values inherit the preceding value. Canvas transforms follow the original skew/scale equations documented in [Reanimator.cpp](https://github.com/Patoke/re-plants-vs-zombies/blob/main/Sexy.TodLib/Reanimator.cpp). Independent feet, knees, forearms, jaw, head, stalk and leaf tracks keep the original animation shape and draw order.

No full-body sprite is divided into rectangles. Each body part draws its entire source PNG, and a rig remains in the procedural fallback until all of its parts have loaded. Independent head-only shooting clips are combined with the concurrent stem/leaf idle clip so shooting never hides the rest of the plant. Losing a cone, bucket or football helmet changes an armor overlay while retaining the same body family. Football shoulder pads remain independent layers over the complete original torso; they never replace the torso texture.

Five plant health stages add progressively more leaf droop, vein cracks and red botanical sap. Wall-nuts and Tall-nuts use their original cracked textures as part of those stages. The fire tint, laser tint and spiky chestnut adaptation are custom Garden Siege variants; they are not additional original Plants vs. Zombies characters. Garden Siege combat, health and animation timing remain custom rules rather than an exact simulation of the original game.
