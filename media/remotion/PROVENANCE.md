# Point · Example · Check

Original fictional speaking example authored for SpeakKai; no source footage, voice, learner likeness or testimonial. Two languages use the same suggestion, observed detail and listener question. 3 beats × 6 seconds, 1080×1080, 30fps. Remotion 4.0.522, React19.2.3. Windows system Arial/Microsoft YaHei; font files not distributed, other machines may differ. Colors #102348, #ffdc38, #ffffff, #cedbf5. No CSS animation; rendered frame drives content/fades.

From this directory: npm ci; npx remotion studio --no-open --port=4330. Render each composition PointExampleCheckEN / PointExampleCheckZH with npx remotion render src/index.ts <ID> ../../public/media/point-example-check-<en|zh>.mp4 --codec=h264 --crf=25 --concurrency=2 --muted. Render poster using npx remotion still src/index.ts <ID> out/poster-<en|zh>.png --frame=45. From repo root run node scripts/prepare-motion-assets.mjs to optimize posters, verify actual streams and record SHA256. The first English output was losslessly remuxed by ffmpeg to remove Remotion's silent AAC; future --muted renders produce the required one-stream output directly.

Playback and complete static alternatives live at /watch/ and /zh/watch/. No autoplay/loop; preload none. Plain HTML contains every instructional sentence. User starts and pauses with native controls. Poster remains visible without media loading. Rendered contact sheets at out/review-en.png and out/review-zh.png were opened; these are local QA intermediates, excluded from Git. Final outputs and manifest are committed. CI verifies byte hashes; rerendered changes require fresh technical and visual review.
