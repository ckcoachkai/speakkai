# Descriptive student skill journeys

Kai confirmed descriptive, individually customized evidence diagrams on September 16, 2026. Each student's diagram evolves as further comments are reviewed. No numerical rating, mastery level or common target shape is implied.

`public/data/feedback-skills.json` maps full, verified reports to descriptive course criteria. Profiles use `classId/studentId`; records use exact session IDs. Each record stores `evidenceSignature([record])` and skill entries `{criterion, en, zh}`. The two language fields are zero-based paragraph indexes into the original full bilingual feedback, separated by blank lines. They must refer to equivalent material. Quotes are rendered directly from those reports, never reconstructed from a short summary.

Read the full relevant original teacher notes, polished reports and published EN/CN before changing mappings. Select only criteria actually addressed in that student's comment; a comment may contain an observation, a concern or a practice direction. A practice direction is not achievement. Keep the exact quote and source link so the distinction is visible. The nine criteria cover ideas/reasoning, organization, voice/clarity, timing/pacing, gestures/posture, audience connection, language choices, preparation/recovery and listening/participation. Adapt which criteria appear to the student, not to a compulsory scorecard. Do not infer course placement or join students across classes.

During weekly review, compare individual record signatures first. Preserve unchanged mappings. New or changed comments stay pending until fully reviewed, while unchanged earlier evidence remains available. Review each affected skill assignment and its EN/CN paragraph before replacing the signature. An absent or missing session has no skill assessment. A skill not revisited in a later lesson remains explicitly not reassessed; do not carry its state forward or turn the gap into decline. Later attempts within one lesson share that lesson's date. Only supported reviewed comparisons may describe cross-lesson change.

Held identities must not acquire skill mappings. Resolve them only from explicit identity evidence. Public empty states do not disclose private reasons. Each profile still has a diagram area when no reviewed evidence is available. New profiles are derived from feedback automatically and show pending until reviewed.
