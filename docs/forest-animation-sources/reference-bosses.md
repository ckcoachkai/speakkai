# Nine reference bosses

These are hand-authored, simplified vector interpretations of the nine user-supplied PNG references, not embedded photographs or exact image traces. Seven visual designs and two alternate zombie movement variants make nine selectable bosses.

Editable animated SVGs live in `public/forest/animations/`. Rebuild their transparent game frames with `node scripts/build-forest-reference-bosses.mjs`. The standalone SVGs use articulated SMIL transforms; the game uses 24 baked frames per loop to follow the game clock. Gentle motion and encounters hold the base frame while the shared character rig supplies reduced motion, localized punch reactions, dancing and hand props.

Input order: Golden Cow, Sunset Cow Duo, Round Pikachu, Ultraman, Gundam, Garden Zombie, Block Zombie, Block Zombie Shuffle, Garden Zombie Groove. Backgrounds were omitted when drawing the vectors. The repeated zombie references have different movement amplitudes.

The existing shared music, text quotes, skeleton sounds, hit effects, ten recoil styles, eight-second dance and colorful 6–7 props apply through the same runtime as the original cast.
