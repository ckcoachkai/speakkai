## Fictional scene and prompt

Use an AI-generated, clearly labeled **fictional scene**: “AI-generated illustration for a speaking exercise; no real venue or event.” Full text description: *A small stage holds one speaker mark and a simple lectern. Three empty audience positions are labeled left, centre and right. A single spotlight falls on the speaker area; no people, logos or identifiable location appear.*

Ask the learner to:

1. **Observe:** name only visible details.
2. **Imagine:** offer one possibility using “might” or “could.”
3. **Speak:** state that possibility without presenting it as fact.

Keep the image static and user-controlled through a “Show the prompt” reveal, with the complete text prompt beside it.
