### Concrete pattern to adapt for SpeakKai

The useful pattern is the sequence and the parent-readable purpose of each step, rather than the branded course names:

`准备一个小目标 → 开口完成任务 → 得到一条具体反馈 → 再试一次 → 记录下一步`

For a speaking session, the parent-facing recap can answer three simple questions:

- What was the learner trying to make the audience understand?
- Which observable choice did they practise (for example, one central point, a pause, a transition, or a clear ending)?
- What is the one next attempt the learner understands?

That keeps feedback concrete and actionable without promising confidence, competition results, or a fixed level outcome. A short practice resource can mirror the same loop: prompt, first attempt, one adjustment, second attempt, next practice.

## Parent-friendly content opportunities

- Put “what happens before, during, and after practice” beside a course or coaching inquiry, using only SpeakKai’s approved session details.
- Show one tiny task and one feedback sentence so a parent can picture the learning experience before contacting Kai.
- Translate feedback into an observable next action: “move the main idea to the first sentence,” “pause before the example,” or “end by naming what the listener should remember.” These are examples of feedback language, not learner diagnoses.
- Let parents send age/grade, speaking goal, event deadline, and preferred format through WeChat. They do not need to send school records, student names, or recordings in the first inquiry.
