## Implementation and architecture

One shared contact component produces English and Chinese pages. Optional audience, goal, group, delivery and timing prompts create a local, editable WeChat draft. School direction uses an independent allowlist. Changing fields preserves manual edits until explicit rebuild; clipboard feedback reports the real result. No inquiry is sent or persisted. A language switch drops query context and draft. Ten reciprocal language pairs now cover all core flagship pages. Legacy tools and schedule remain English and are labelled accordingly.

The V25 architecture review retains Astro static output, React practice islands and local Keystatic. No unmet server requirement justifies Next.js migration. Runtime labels live in page JSON, keeping contact JavaScript at 4.55KB raw; no dependency was added.
