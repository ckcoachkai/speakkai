# Version 16 — Text that reflows, architecture with a reason

Status: release candidate. Entering champion V15: 43.5/55.

## Research before edits

Fresh New Oriental hierarchy, Coursera offer structure, official Next.js static-export constraints and W3C resize/reflow guidance informed this cycle. Independent repository review confirms Astro static output, selective React, local Keystatic and GitHub Pages meet current requirements. Source limitations are recorded in research/v16-china.md, v16-global.md and v16-review.md. No broad social-platform sweep, conversion study or competitor browser audit was performed.

Decision: retain Astro for current needs and reassess if requirements change. ARCHITECTURE.md records objective migration gates and parity obligations. No product points are awarded for the framework decision.

Hypothesis: long words and fixed grid minimums cause avoidable horizontal scrolling and fragmented numbers when visitors enlarge text. Wrapping and content-sized tracks should preserve content and controls without clipping or reducing text size.

## Implementation and comparison

Added inherited overflow-wrap:anywhere to the flagship shell. Practice step-number columns grow with their content while keeping each number together. Mobile experience, course-fact and role grids use font-relative minimums so enlarged copy can stack rather than fragment across narrow cells. Ordinary desktop layout remains unchanged.

The baseline scripted test doubled all precomputed font sizes at a 320×900 viewport. V15 document widths were 519,354,369,427,353,336,371,336,336,336,489,336px in the twelve-route release order. V16 initially removed page overflow but visual review still found vertical 0/1 digits and fragmented experience figures. The final grid fixes resolved those observed defects.

Final V16: all twelve routes have scrollWidth=clientWidth=305px with a 320px viewport (15px scrollbar). This is a scripted doubled-font stress test, not native browser zoom or a complete WCAG conformance result. Normal 320×900 and 1440×900 route geometry also passes, with version16 on every route. Resource thumbnails were initially deferred by lazy loading and all loaded after scrolling.

## Browser and technical validation

Reviewed normal mobile/desktop Home and enlarged Home, expanded navigation, experience figures, Chinese course facts, practice steps, guided practice and Chinese inquiry screenshots. Step numbers remain horizontal; experience/course facts stack; controls and content remain reachable. Enlarged Menu opens and Escape closes it with summary focus. The English one-minute guide advances through all five steps, completes and retries, retaining in-bounds controls and heading focus. Enlarged Chinese inquiry generation keeps fields/buttons within the page and focuses the editable draft. Temporary font mutations were restored through reload.

Final build: 49 pages, zero errors/warnings, seven existing hints. Twelve flagship route checks and 210 local targets; twelve structured-data graphs and eighteen sitemap targets; course languages/editorial, practice parity, twenty inquiry/Speak tests, schedule privacy, byte budgets and git whitespace checks pass. No new runtime JavaScript was added.

Native 200% browser zoom, screen readers, other engines, physical printing, field performance and actual visitor conversion remain unverified. The test does not prove every enlarged-text state across the legacy tools.

## Critique and champion decision

Improved: content reflows under a demonstrated stress condition, numeric labels remain intact and existing controls are usable. Average: extremely enlarged headings still wrap inside words, and dense pages require substantial vertical scrolling. Ahead of a purely cosmetic redesign: this candidate addresses measured failures without a framework rewrite. Behind mature training brands: independently attributable outcomes, richer demonstrations and real audience research remain missing.
