# Version 09 — A shorter mobile header

Status: built and locally verified; live verification pending. Entering champion V08: 41/55.

## Research before changes — 2026-09-07

Refreshed EF China all-courses and Duarte homepage HTML. EF exposes audience-led course choices and human contact; Duarte delivers separate mobile navigation controls and a visible contact route. WAI disclosure, WCAG resize-text/reflow and MDN native-control guidance support a compact, labelled disclosure while keeping contact outside it. These static source checks do not establish either competitor's mobile usability. See v09-china.md and v09-global.md in the research directory for URLs, observations and unchanged social-platform access limitations.

Hypothesis: a native disclosure can reduce narrow-screen header height while preserving all four navigation destinations, direct contact, keyboard operation and no-script access. Existing labels, content, hosting and the Astro/React/CMS architecture remain intact.

## Implementation and validation

One shared navigation data list supplies desktop links and a native details/summary mobile menu. The visible contact link remains outside the menu. Mobile rows have at least 44px target height, a clear focus outline and natural document flow. Enter and Space use native behavior; the small enhancement handles Escape with focus return and same-page anchor focus. Consolidated competing mobile header styles; desktop header can wrap when needed. No new dependency or animation was added.

47-page build: zero errors/warnings, seven existing hints. Ten flagship routes/174 local targets, ten structured-data graphs, sixteen sitemap targets, three practice lessons, eighteen inquiry/Speak regressions and schedule privacy pass. git diff --check passes.

Chromium production preview: at 320x900, the closed header fell from 206.61px to 114.43px (44.6%); homepage H1 top moved from 299.01px to 206.82px. No horizontal overflow at 320, 720, 721 and 1440px. Desktop header is 84px at 1440; just above the breakpoint at 721 it wraps to 140.85px. Mobile expanded links measure 46.40px high. Enter/Space toggling, Escape from a link to summary, same-page navigation to focused work section, Resources navigation and direct Contact route pass. With JavaScript disabled, the native menu still opens and exposes all four links. Screenshots of the open mobile menu and desktop hero were reviewed.

Targeted text check: temporarily doubled every computed header font size at 320px, producing 28px menu/contact labels and 32px links. The open header reflowed without horizontal overflow or clipped links and Escape remained usable. This tests CSS text enlargement of the header only, not native browser text settings or the entire site. All temporary text/script emulations were restored.

## Critique and challenger

Improved: considerably more of the first message is visible on a narrow screen; contact stays immediately reachable; no-script users retain the navigation. Average: the closed header still uses two rows, intermediate desktop widths wrap, and English-only copy remains a barrier for some parents. Ahead of the checked catalogue: short routes to specific practice and an uncomplicated contact path. Behind established brands: attributable proof, bilingual depth, demonstration media and content range.

Scores in consistent category order: 3.5,2,4.5,4,4,4,4.5,3.5,3,4,4.5 = 41.5/55. Only mobile usability rises, based on measured layout improvement and retained task paths. No conversion, learning, ranking or field-performance gain is claimed. Actual screen readers, other browser engines, native browser text resizing and full-site 200% text remain unverified.
