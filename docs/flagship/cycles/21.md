# Version 21 — Smaller portrait requests and leaner markup

Status: release candidate. Entering champion V20: 44.75/55.

## Research before edits

Fresh Gaotu and Toastmasters homepage HTML inspections showed purposeful text/media entry points and limits of markup-only performance inference. MDN documented srcset/sizes resolution switching. These references did not establish comparative speed. See research/v21-china.md and v21-global.md.

Baseline browser observation: at approximately 1x DPR, both 320px and 1440px viewports requested the 66,486-byte 1400px portrait, rendered at 260.66px and 497.78px respectively. Hypothesis: smaller resolution candidates reduce the selected request while preserving the current crop and visual role.

## Implementation

Three reproducible 360/720/1080px WebP derivatives supplement the original 1400px source. No generated identity or creative edit is involved. The hero keeps dimensions, alternative text, high priority and the same CSS crop, with explicit eager loading. Below-fold stage and contact images remain lazy.

The V20 method navigation is extracted into FlagshipMethodExamples. Its local styles no longer add scope attributes across unrelated homepage markup. Published content gating and the four example links remain intact. No JavaScript, server or framework change is required.

## Validation

Build: 49 pages, zero errors/warnings, seven existing hints. Twelve-route/anchor, metadata, bilingual/editorial, practice, 21 inquiry/Speak, schedule privacy and byte-budget checks passed. Generated files have the declared square dimensions. Homepage HTML fell from 19,468 to 16,663 bytes; all candidate images fit the existing conservative 400 KB limit without relaxation.

Fresh uncached browser loads selected 7,962 bytes at 320px and 20,402 bytes at 1440px, versus 66,486 previously. The rendered portrait dimensions were unchanged. Settled desktop portrait/crop and method navigation were reviewed, with the portrait also inspected at mobile size. All twelve routes fit actual 320px/1440px widths; the homepage also fits doubled precomputed fonts at 305px client width. The extracted school link reaches its published practice. Temporary cache/font overrides were restored.

These are asset-request measurements. No whole-page loading-speed, field Core Web Vitals, high-density physical-device or conversion claim is made. Other engines, native zoom and screen readers remain unverified.
