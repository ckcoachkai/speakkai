# Version 18 — A bilingual pause-and-retry example

Status: release candidate. Entering champion V17: 44/55.

## Research before edits

Fresh EF China research exposed recognizable story/speech activity formats but no inspectable feedback exchange. Cambridge English's children's activities provide skill and level context, with no verified feedback transcript or outcome evidence. W3C page/part language guidance supports the existing route language boundaries. Read research/v18-china.md and v18-global.md for sources and limitations. Root retained the current pause feedback rather than adding a second teaching change from a research suggestion.

Hypothesis: the existing isolated coach quote becomes easier to understand when a parent can read a short fictional first attempt, the feedback and a retry using the same words with a visible pause instruction.

## Implementation

Both course routes now show three static stages: first try, coach feedback and retry with one pause. The original coach quote remains. The fictional two-sentence kite story shares the same opening and ending in both displays. The pause marker is ordinary visible text with a localized explanation that it is not a word to say. The listener is asked why the event mattered to the speaker and whether a pause changes what they hear; no outcome or fixed duration is asserted.

Two new required fields per language, practiceOpening and practiceEnding, are editable in Keystatic. The form tells the editor that both displays reuse the text and that English and Chinese need paired review. Tests require identical first/retry wording and exactly one pause location. Labels and cue guidance remain in localized template copy. Fixed course scope, contact routes, metadata and operating boundaries remain outside the form.

No new JavaScript, audio, recording, framework or server requirement exists. Astro retention remains appropriate. CONTENT-EDITOR.md documents the paired review; CONTENT-STRATEGY.md is a working handover draft to reconcile at V30.
