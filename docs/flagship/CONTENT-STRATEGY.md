# Content strategy — working draft through V17

Reconcile against the final V30 release before handover.

## Serve a speaking moment

Parents need age, learning scope, an understandable practice task and a direct way to discuss suitability. Schools need a curriculum or workshop purpose, participant context and delivery responsibilities. Companies need audience fit, a speaking challenge and a clear distinction between a keynote, workshop and individual coaching.

Give each audience a dedicated route. Use the shared Think / Practise / Grow method to connect the offers, while making each example appropriate to its reader. Let a visitor try a useful free practice before contacting Kai.

## Editorial sequence

1. Start with a real question from Kai's work, stripped of names and private details.
2. Write one original practice: purpose, audience, materials, steps, approximate timing, listener check and one retry.
3. Label invented scenarios as fictional. A worked example demonstrates wording; it does not establish learning or business results.
4. Check the content source, numerical scope, language, accessibility and public-use rights.
5. Use local Keystatic for supported fields, inspect the generated page, run the release checks and publish through the existing workflow.
6. Confirm the public page and the next action after publication. Saving in the editor is not publishing.

## Language and provenance

English is the current broad site language. The confirmed Fall course and one-object practice have Simplified Chinese routes. Keep reciprocal language links explicit, with warnings where switching resets local practice. Compare meaning, activity sequence and fixed facts across languages; do not infer fluency or professional translation review from schema parity.

Keep a source and review note with each practice and paired course narrative. Those notes are editor-only. Preserve uncertainty about dates, fees, delivery, availability and outcomes. Do not convert a fictional quote into a testimonial by adding a name or portrait.

## Media pipeline

Prioritize short approved demonstrations: a speaking task, one coaching adjustment and another attempt. Documentary footage requires verified public-use permission, particularly for identifiable children, schools or client work. Generated illustrations and animation should explain the practice and be presented with accurate provenance. They cannot supply missing testimonials, partnerships or authentic event footage.

Use opt-in playback, a useful poster or static alternative, captions/transcript as applicable, local optimized assets and explicit byte budgets. Keep basic instruction and the next action available without playback.

## What to learn next

Collect audience feedback before expanding the library: Can the reader identify the offer, explain the practice and find the next action? Ask which details are missing. Record observations separately from inferred preferences. No comprehension, learning, inquiry-quality or conversion experiment has been completed in these cycles.

Candidate content: age-appropriate story examples, classroom explanation and listener feedback, workplace briefings, rehearsal questions, and event preparation. Publish at a sustainable cadence based on reviewed material; this draft does not create a publishing schedule or automation.
