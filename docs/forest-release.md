# The Hungry Forest

Published route: `/forest/`. Resources links are generated by `ToolsGallery.astro`, including the Chinese Resources page with an English-interface label. `/forest/` is also in the curated sitemap.

The browser-only game has editable names, local saved appearances, no-repeat turns, ten selectable characters, narrated quotes, joint-driven 2D animations, flame effects, visible accelerating runners, banana boosts, Pause/Resume, and Wild/Gentle motion. It does not upload names. Saved rosters belong to the browser and website origin; localhost saves do not automatically transfer to speakkai.com.

Source: `src/scripts/forest/` and `src/pages/forest.astro`. Media: `public/forest/art/`. This release imports the existing local game; original generated portraits and characters were created with the built-in image-generation tool. Public assets are WebP/MP3 encodings of those images and Windows synthetic narration. Public-figure quotes are fictional; narration does not impersonate their voices. Rabbit is an original substitute for the image tool's blocked Bugs Bunny output. Koala remains a labeled provisional interpretation of an unclear dictated name.

Checks: `npm run build`, `node scripts/check-forest.mjs`, and the existing deployment workflow checks. Browser checks cover startup, selection, pause/resume, character switching, voice download, and Resources navigation. Device speaker listening is not independently verified.

Rollback: revert the forest release commit and push main; the normal Pages workflow restores the prior site. No pre-existing site content or persisted roster requires migration.
