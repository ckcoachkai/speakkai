# Schedule area and grade labels

Public class labels include only an allowlisted approximate area and the grade explicitly present in the source booking. They never reuse arbitrary source text or student names. Private lessons remain `VIP 1-to-1 booked`. Missing grades are omitted, not inferred from a time slot. Internal labels retain the existing source details.
