# SpeakKai Travel — Lakeside escape

## Style Prompt
A refined travel editorial for a short Suzhou Bay resort escape. Expansive photography, ivory paper, deep evergreen, warm brass details, expressive serif headlines, restrained navigation and useful trip controls. Preserve all existing itinerary facts and unconfirmed booking status.
## Colors
- #f7f5ef: warm paper
- #143d35: evergreen ink and actions
- #a7834b: brass accents
- #dfe6da: sage dividers
- #ffffff: photo typography
## Typography
Playfair Display for editorial headings; DM Sans for navigation, controls and prose.
## Motion
Quiet camera movement, 8-second looping landscape film. Pause control and reduced-motion poster. No sound or compulsory animation.
## What NOT to Do
No fictional hotel features or ratings. No simulated booking checkout. No fake native-4K claims. No carousel autoplay. No oversized technical explanations in the main flow.
## Blender contract
Refined illustrative East Taihu landscape: organic shoreline, layered terrain, carefully articulated resort wings with windows, roofs, courtyard and pool, planted paths, bridge, city departure district and continuous route. Smooth geometry and realistic material relationships, within 250k triangles. It is an artistic route sketch, not surveyed geography. Deliver deterministic Python, blend, GLB, 3840x2160 render and multiview evidence; validate fresh GLB import. Stages: proportions, primary/secondary forms, topology, materials, polish, export/reimport.
## Figma discovery
No Code Connect files. New file empty, no local variables or styles. Product fonts verified in Figma. Simple Design System Button available; use an instance for the main action. Bespoke editorial layout uses the source palette above.
## HyperFrames brief
Eight-second silent landscape postcard for this website, 16:9, 3840x2160 master; site gets a compressed smaller derivative. Detailed Blender landscape is the native-resolution source. Calm camera drift with an editorial route title, matching this design. One finished version as part of the requested website redesign.
